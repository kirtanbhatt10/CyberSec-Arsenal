# Security Policy

## Reporting a vulnerability

If you find a security issue **in one of these tools** (for example, a scanner that can be crashed or abused by malicious input, or a detection that leaks secrets in its output), please report it privately via GitHub's **[Report a vulnerability](../../security/advisories/new)** button rather than a public issue.

Please include:

- Which project and file are affected
- Steps or input to reproduce
- The impact you expect

You can expect an acknowledgement within 7 days.

## Scope

These are educational tools. Reports about the *techniques they detect* (e.g. "SQL injection exists") are out of scope - but false negatives in detection rules make great regular issues and PRs!

## Responsible use

Only run these tools against systems you own or have explicit, written authorization to test.
